# Appearance Settings

## Scope

Offer `System`, `Light` and `Dark` with immediate preview and persisted preference. Explain the active resolved theme when System is selected. Apply changes without a full reload or theme flash.

Offer `English` and `Simplified Chinese` as a personal language preference on the same page. Language names appear in their native form. Apply the selected locale immediately without a full reload or a route change. Follow `docs/internationalization/README.md` for locale resolution, persistence, and fallback.

Verify application surfaces, Monaco, charts, diagrams, scrollbars, overlays and browser `color-scheme`. Appearance is personal even though the route appears within the Settings experience.
