# Member Settings

## Scope

Manage members and invitations with identity, role, invitation state and relevant activity. Support invite, resend, revoke and role changes according to permission. Protect required administrators and explain consequences before removal.

Define empty invitation, pending, expired, duplicate, permission, last-administrator and partial-failure states. Do not expose private profile information unnecessarily.
