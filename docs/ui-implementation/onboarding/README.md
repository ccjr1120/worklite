# Onboarding

## Flow

Use a resumable sequence with visible progress and one primary outcome per step:

1. Create a team or join an available invitation. Ask for team name and an editable generated slug when applicable.
2. Configure a model provider, test credentials, or defer only when the product remains useful.
3. Create the first agent through concise guidance or a small set of intentional templates.

Explain the team as the access boundary and the agent as instructions, model, skills and tools. Never read back secrets. Invited users skip team creation. Returning users resume their incomplete step. Finish at the created agent or Home with a clear next action.
