# Invitation Acceptance

## Experience

Display the inviting team and invited email. New signed-out users create an account and join in one flow. Existing matching users see `Join workspace`. Account mismatch explains switching accounts. Expired invitations explain recovery.

The team and invited email are not casually editable. Successful acceptance opens that team and skips team creation. Define loading, invalid, expired, already-used, unauthorized, accepting and success states.
