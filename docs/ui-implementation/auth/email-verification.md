# Email Verification

## Experience

Show `Check your email`, the destination address, a restrained mail icon, resend, and `Use a different email`. Resend provides cooldown and `Email sent` feedback. Recheck verification on focus or through restrained polling, then continue to onboarding.

Define initial, checking, sent, throttled, verified, expired and network-error states. Never imply delivery is guaranteed.
