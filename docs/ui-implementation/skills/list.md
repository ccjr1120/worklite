# Skill List

## Structure

Use the collection pattern with create and archive-upload entry points as supported. Rows show name, source type, current version, validation state and update time. Clearly distinguish drafts from published versions.

Define empty, uploading, validating, invalid package, filtered no-results, permission and unavailable-file states.
