# Skill Editor

## Layout

Separate the package tree from the selected file editor. Use Monaco where appropriate. Surface validation by file and severity. Support online creation, archive upload, instructions, package inspection, validation and immutable publication.

Show executable-content restrictions and sandbox limits when relevant. Do not imply validation guarantees runtime safety. Protect against unsafe previews and define unsaved, saving, validating, invalid, publish, read-only version and large-file states.
