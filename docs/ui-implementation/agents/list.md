# Agent List

## Structure

Use the collection pattern with `Create agent`. The Agents surface provides page-level views for `Agents`, `Skills`, `MCP Servers`, and `Providers`, in that order; these views do not create nested workspace navigation. Each row emphasizes agent name and responsibility, model, skills or tools, published version, recent state and update time. Identity uses a restrained geometric mark or initials, not character artwork.

Define first-use empty, filtered no-results, loading, partial failure, permission and long-name states. Filters and sort should remain navigable and persist when useful.
