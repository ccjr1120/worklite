# Artifact Details

## Preview

Use the safest appropriate preview. Text and structured data receive readable viewers with copy or download. Supported media receives a constrained preview and metadata. Unsupported or potentially unsafe content receives metadata and download without inline execution.

Always link to the producing run and step. Large content loads without blocking the shell. Define loading, processing, preview failure, unavailable storage, permission and download failure states.
