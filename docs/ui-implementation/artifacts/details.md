# Artifact Details

## Preview

Use the safest appropriate preview. Text and structured data receive readable viewers with copy or download. Supported media receives a constrained preview and metadata. Unsupported or potentially unsafe content receives metadata and download without inline execution.

Identify the producing run and step; with standalone Run routes removed, this provenance is displayed as non-navigation context while the Workflow remains directly addressable. Large content loads without blocking the shell. Define loading, processing, preview failure, unavailable storage, permission and download failure states.

Artifact details expose a destructive Delete action. Successful deletion closes the dialog and returns to the Workflow collection; failure remains visible in the dialog.
