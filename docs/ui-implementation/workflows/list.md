# Workflow List

## Structure

Use the collection pattern with `Create workflow`. Rows emphasize name, draft or published state, node count, last run, last run status, and update time. Provide direct continuation to drafts and clear access to immutable versions.

Define first-use guidance, filtered results, validation attention, loading, permission and long-name states.
