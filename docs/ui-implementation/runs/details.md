# Run Details

## Structure

Show run identity and status, workflow version, timestamps, duration and initiator; deterministic graph execution progress; selected-node input, output, retries, model, skill, MCP and tool activity; logs and events; leaf results and artifacts.

Show `Cancel run` only for cancellable states and never confuse cancellation with hiding a panel. Failures identify the failing step, known cause, retained completed work and supported recovery. Reconnection resumes without duplicate events. Log streaming preserves manual scroll position.
