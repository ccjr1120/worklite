# MCP Server List

## Structure

Use the collection pattern with `Connect MCP server` in the right side of the toolbar directly above the table. Rows emphasize name, connection status, transport, allowed-tool count, published version and update time. Connection and version status remain distinct.

Define first-use guidance, testing, unreachable, authentication failure, filtered no-results, permission and secret-configuration attention states.
